The first dynamic equation experiment established the following separation:

1. Canonical scientific data can live independently.
2. Entities can provide physical properties.
3. Equations can operate on generic numerical inputs.
4. Callers compose the pieces.
5. Equations return values rather than performing I/O.

The Earth–Moon gravitational-force calculation was used as the initial
reference case, followed by arbitrary numerical inputs to verify that
the equation responds dynamically to its arguments.

Current unresolved questions:

- How should physical units be represented?
- How should equations handle invalid inputs such as `distance = 0`?
- How should equations interact with changing simulation state and time?

This experiment is evidence for the current architectural direction,
not a final API commitment.
