MUST: mandatory requirement.
MUST NOT: prohibited practice.
SHOULD: expected practice, with a documented reason for deviation.
MAY: permitted option.

Correctness: What must always be true?
Reliability: How should failures be handled?
Safety: What operations must be prevented or controlled?
Determinism: What guarantees reproducible behavior?
Testing: What evidence is required before code is trusted?
Maintainability: What standards must future GPSE code follow?
Integration: How must mission-critical components interact?
