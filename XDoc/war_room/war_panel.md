# PANEL USAGE CONVENTIONS

### Status Classification

| Status | Meaning |
|---|---|
| CONCEPT | Initial idea |
| RESEARCH | Under investigation |
| PROPOSED | Suggested, awaiting approval |
| UNDER REVIEW | Actively debated |
| APPROVED | Accepted decision |
| DEVELOPMENT | Being implemented |
| EXPERIMENTAL | Implemented but not established |
| VERIFIED | Tested against defined requirements |
| STABLE | Established and maintained |
| DEPRECATED | Retained but no longer recommended |
| ARCHIVED | Development concluded or suspended |

### Documentation Rules

1. Preserve significant decisions and their reasoning.
2. Never present an unapproved proposal as an established fact.
3. Remove redundant descriptions while preserving unique information.
4. Keep technical specifications distinct from philosophical principles.
5. Record unresolved questions rather than prematurely resolving them.
6. Update the panel when architecture or decisions materially change.
7. Preserve superseded decisions for historical context.
8. Use links to supporting documents rather than duplicating extensive material.
9. Scale sections to the project; mark irrelevant sections as not applicable rather than inventing content.
10. Treat the War Panel as a living development record, not a static proposal.

**War Panel philosophy:**

A War Panel is the central planning, architectural, technical, and decision-making reference for developing a GPSE project, module, or system.
